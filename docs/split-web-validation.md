2026-10-18（日本時間）。模擬データだけを使ったローカル検証。

| 対象 | 観測結果 |
| --- | --- |
| macOS / Python 3.14.6 | `REQUIRE_CRYPTO=1`、警告をエラー扱いにして全96件成功。実行ログは[こちら](evidence/2026-10-18-split-web/tests-macos.log)（SHA-256 `c3430d7a2972dfd7005c90fa6a70917534f5cdeaac1441dea035a2a219151105`）。 |
| 分離WebのHTTP統合テスト | 新規10件成功。実AnonCredsで同意・拒否、認証境界、失効と再発行、鍵更新、再ペアリング、制限中のログアウト、検証中のセッション失効を確認。二つのサービスを実際の別プロセスで起動するテストを含む。 |
| JavaScript | `node --check split_web/verifier.js` と `node --check split_web/wallet.js` が成功。 |
| ローカルブラウザ | 検証者・ウォレット双方の画面表示と模擬ログイン、検証者での要求作成、ウォレットでのログアウトを操作確認。 |

使用したブラウザ操作環境では、検証者画面が開いたウォレットのポップアップを一覧から取得できなかった。
そのため、**実ブラウザでの画面間メッセージ、同意・拒否の終端表示は未確認**。
別プロセス間のAPIを通す同意・拒否は上記のHTTPテストで確認したが、画面操作の代わりとは扱わない。
Windows・UbuntuのCI結果はPRのチェックに記録する。

これはループバック上の模擬資格情報に対する検証であり、実免許証、実ユーザー、警察の状態照会や本番運用の検証ではない。
