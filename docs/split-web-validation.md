使用したブラウザ操作環境では、検証者画面が開いたウォレットのポップアップを一覧から取得できなかった。
そのため、**実ブラウザでの画面間メッセージ、同意・拒否の終端表示は未確認**。
別プロセス間のAPIを通す同意・拒否は上記のHTTPテストで確認したが、画面操作の代わりとは扱わない。
Windows・UbuntuのCI結果はPRのチェックに記録する。

これはループバック上の模擬資格情報に対する検証であり、実免許証、実ユーザー、警察の状態照会や本番運用の検証ではない。

同日の画面文言の見直しでは、利用者向けの説明を「受付」「確認内容」「共有する／今回は共有しない」にそろえた。
サンプルデータの範囲と、証明に含めない免許情報・受付に伝わる識別子は引き続き表示する。
3本のJavaScriptの構文と、3画面のIDの重複・参照欠落を確認した。
ブラウザでは、分離版のログイン表示・受付での確認開始、従来版の共有する／共有しない両方の終端表示を操作確認した。
