## PR #6レビューと確認内容の再送（2026-10-18）

同意待ちに受付の開始ボタンをもう一度押すと、新しい確認IDで上書きされ、Walletから届く古いIDの結果を受付が受け取れなくなる不具合を再現した。

操作期限が切れた場合や、受付のログアウトで確認内容を破棄した場合は、Walletを再読込してから新しい確認を始める。
