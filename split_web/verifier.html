SYNTHETIC VERIFIER

必要な条件だけを確認する

この画面で確認要求を作ります。開いたウォレット画面で利用者が内容を読み、同意したときだけ証明が届きます。

実免許証・実ユーザーの確認ではありません。模擬資格情報の署名、条件、模擬失効情報を確認します。警察の停止・取消し・失効照会は行いません。

01 / ACCESS

検証者としてログイン

検証者プロセスの端末に表示されたデモ用コードを入力してください。

このコードはローカルデモの操作用です。実在人物の認証ではありません。

02 / REQUEST

確認要求を作る

発行鍵を選ぶと、その鍵に結び付いた模擬資格情報の条件を要求します。旧鍵が併存中なら、その資格情報も選べます。要求を作る直前に鍵の一覧を更新します。
